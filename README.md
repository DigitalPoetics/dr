# [Diagrammatic Readings](https://www.diagrammaticreadings.com)
### Computational and Materialist Approaches to Literary Analytics and Visualization


Companion website for my dissertation, ["Diagrammatic Readings."](http://rave.ohiolink.edu/etdc/view?acc_num=ucin1758102497551938)

Made with Astro.js, the theme currently supports:

- Vector-based in-text search query UI
- D3.js visualizations for Digital Humanities projects
- Indexed blog posts
- Experiments in data visualizations & more...
